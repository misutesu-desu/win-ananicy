# WinAnanicy 1.0.0

WinAnanicy is now a polished, safe, and easy-to-use Windows optimization suite with a premium desktop control center.

## English

- Premium dashboard with live engine health, process activity, rule management, and settings.
- One-click Game, Creative, Background, and Strict Saver presets.
- Safe per-user engine that restores every changed process setting when a rule stops applying.
- English and Turkish support across both the application and installer.
- Automatic configuration backups, import/export, strict validation, and readable activity logs.
- Optional Windows startup, notification-area controls, clean upgrades, and a portable package.
- Self-contained 64-bit build: no separate .NET installation is required.

Choose **Setup** for the recommended guided installation. Choose **Portable** if you prefer an extract-and-run package.

## Türkçe

WinAnanicy artık premium masaüstü kontrol merkeziyle güvenli, şık ve kolay kullanılan bir Windows optimizasyon paketidir.

- Canlı motor durumu, işlem etkinliği, kural yönetimi ve ayarlar içeren gelişmiş kontrol paneli.
- Tek tıklamayla Oyun, Üretkenlik, Arka Plan ve Sıkı Tasarruf profilleri.
- Bir kural devreden çıktığında değiştirdiği tüm işlem ayarlarını geri yükleyen güvenli kullanıcı motoru.
- Uygulama ve kurulum sihirbazının tamamında İngilizce ve Türkçe desteği.
- Otomatik yapılandırma yedekleri, içe/dışa aktarma, sıkı doğrulama ve okunabilir etkinlik kayıtları.
- İsteğe bağlı Windows başlangıcı, sistem tepsisi kontrolleri, temiz yükseltme ve taşınabilir paket.
- Bağımsız 64 bit paket: ayrıca .NET kurmanız gerekmez.

Önerilen, yönlendirmeli kurulum için **Setup** paketini; çıkartıp doğrudan çalıştırmak için **Portable** paketini seçin.
