# WinAnanicy 1.0.1

WinAnanicy 1.0.1 is a trust and launch-readiness release.

## English

- Uses GPL-3.0-or-later consistently across the repository, application, and
  packaged documentation.
- Adds a clearer landing page, English product demo, social preview, public
  roadmap, and structured issue templates.
- Documents how to verify release checksums and discloses that the current
  community build is not Authenticode-signed.
- Adds signed GitHub build-provenance attestations for release packages.
- Keeps the same per-user, no-elevation architecture and reversible process
  controls introduced in 1.0.0.

Choose **Setup** for the recommended guided installation. Choose **Portable**
for an extract-and-run package. Download only from the official GitHub release
and verify it against `SHA256SUMS.txt`.

## Türkçe

WinAnanicy 1.0.1 güven ve yayın hazırlığı sürümüdür.

- Depo, uygulama ve paketlenmiş belgelerin tamamında GPL-3.0-or-later lisansı
  tutarlı hâle getirildi.
- Daha anlaşılır proje sayfası, İngilizce ürün demosu, sosyal önizleme, açık
  yol haritası ve düzenli issue şablonları eklendi.
- Sürüm dosyalarının SHA-256 ile nasıl doğrulanacağı belgelendi ve mevcut
  topluluk derlemesinin Authenticode ile imzalı olmadığı açıkça belirtildi.
- Sürüm paketlerine imzalı GitHub derleme kaynağı doğrulamaları eklendi.
- 1.0.0 ile gelen kullanıcı oturumunda çalışma, yönetici izni istememe ve
  süreç değişikliklerini geri alma modeli korunuyor.

Önerilen kurulum için **Setup**, çıkartıp doğrudan çalıştırmak için
**Portable** paketini seçin. Yalnızca resmî GitHub sürümünden indirin ve dosyayı
`SHA256SUMS.txt` ile doğrulayın.
